Monitor AI agents. Manage tmux.

See who's blocked, working, or done. Create and navigate sessions, windows, and panes from one sidebar.

Previously named tmux-agents-mon.

agenmux on github · v0.4.0 · ★ MIT

how it works

no hooks

Detection is scraping-only: agents are identified by walking each pane's process tree, state inferred from the visible screen and title. Nothing runs inside your agents.

six agents built in

Claude Code, Codex, Hermes, Oh My Pi, OpenCode, and Pi. Adding an agent is one small config file — no code.

rust engine

A single daemon uses one persistent tmux control-mode connection. Prebuilt, verified binaries download automatically; Linux builds are statically linked.

native notifications

macOS notifications via a signed Agenmux.app — click one and your terminal jumps to the exact pane. notify-send on Linux.

what's new

whole-tmux navigator

The sidebar lists every session, window and pane in tmux order, with agent status inline — jump to any of them, not just agents. Press . to toggle the agents-only list.

settings, in the sidebar

s opens a Settings view that adapts to narrow panes. Edits are validated, saved atomically and picked up live — a typo never takes a running sidebar down.

tmux management

Create (cc/cs), rename (r) and delete (dd) sessions, windows and panes from the sidebar. Deletes confirm inline and never destroy a session implicitly.

event-driven scanning

Pane activity triggers fast updates through one persistent tmux connection, with periodic reconciliation for background sessions. 

[display]
# defaults shown; set false for the agent-only, read-only sidebar
show_all_panes = true      # or press `.` to toggle live

[tmux_management]
enabled = true             # create/rename/delete from the sidebar
confirm_delete = true

install

Paste this command into your terminal:

curl -fsSL https://snirt.github.io/agenmux/install.sh | sh

Recommended. Clones or updates agenmux, asks for the launcher keys, updates your tmux config after confirmation, and reloads tmux.

With TPM, add this line to ~/.tmux.conf:

set -g @plugin 'snirt/agenmux'

Put it before TPM initializes, reload your tmux config, then press prefix + I to install. Without TPM, follow the manual clone steps.

Requirements: tmux and bash. curl and tar enable the automatic native download; without them, Cargo builds the engine when available. Release tarballs with SHA256SUMS are on the latest release.
