# Rust Sidebar Visual Polish Implementation Plan

> **For agentic workers:** use the `subagent-driven-development` skill to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking.

**Goal:** Make the Rust sidebar easier to scan and safe at narrow terminal widths without changing its existing spinner, blink, selection, navigation, or processless delivery behavior.

**Architecture:** Keep the custom ANSI renderer in `src/sidebar.rs`. Add three private terminal-cell helpers at the existing rendering seam, use them to produce width-safe header/session/agent/title lines, then bound the two overlays to the measured pane. Continue emitting one complete frame and one physical-line mouse map through the existing `Sidebar::emit`/`PaneWriters` interface.

**Tech Stack:** Rust 2021, ANSI SGR, tmux 3.x, `unicode-width`, existing Rust unit tests and shell integration tests.

## Global Constraints

- Keep `SPIN`, `Sidebar::dot`, blink timing, and the selected-row animation unchanged.
- Do not add Ratatui, Crossterm, a theme system, tabs, panels, borders, or new input bindings.
- Preserve one physical terminal line per session heading, one per agent row, and one optional subject line; mouse-row mapping must remain exact.
- Preserve complete-frame rendering for processless panes; do not change `src/pane_writers.rs`.
- This plan targets the Rust UI only. Do not duplicate the work in `scripts/sidebar.sh`; issue #6 owns removal of that fallback runtime.
- Use ellipsis only when text is actually clipped. Never wrap list or overlay lines.

## File Map

- `Cargo.toml` — declare the single focused display-width dependency.
- `Cargo.lock` — record the resolved dependency version; generated by Cargo.
- `src/sidebar.rs` — own terminal-cell clipping/padding, static visual hierarchy, and bounded overlays. No new public interface.
- `tests/navigation.sh` — verify the normal 30-column frame keeps its hierarchy and existing navigation behavior.
- `tests/run.sh` — verify help/version overlays fit a 30×15 sidebar and still return to the list.

```rust
use unicode_width::{UnicodeWidthChar, UnicodeWidthStr};

fn cell_width(text: &str) -> usize {
    UnicodeWidthStr::width(text)
}

fn clip_cells(text: &str, max: usize) -> String {
    if cell_width(text) <= max {
        return text.to_string();
    }
    if max == 0 {
        return String::new();
    }

    let mut out = String::new();
    let mut used = 0;
    for ch in text.chars() {
        let width = UnicodeWidthChar::width(ch).unwrap_or(0);
        if used + width > max - 1 {
            break;
        }
        out.push(ch);
        used += width;
    }
    out.push('…');
    out
}

fn pad_cells(text: &str, width: usize) -> String {
    format!("{text}{}", " ".repeat(width.saturating_sub(cell_width(text))))
}
```

Do not make these functions public and do not create a new rendering module for three functions with one caller.

- [ ] **Step 3: Implement session and agent-column helpers**

Add near the Task 1 helpers:

```rust
fn session_heading(name: &str, count: usize, cols: usize) -> String {
    let suffix = format!(" {count}");
    let name_room = cols.saturating_sub(cell_width(&suffix) + 1);
    let name = clip_cells(name, name_room);
    let rule = "─".repeat(
        cols.saturating_sub(cell_width(&name) + cell_width(&suffix) + 1),
    );
    format!("{name} {rule}{suffix}")
}

fn agent_column_width(
    rows: &[PaneRow],
    visible: &[usize],
    cols: usize,
) -> Option<usize> {
    (cols >= 40).then(|| {
        visible
            .iter()
            .map(|&i| cell_width(&rows[i].agent))
            .max()
            .unwrap_or(0)
            .min(10)
    })
}
```

Keep both helpers private. The 40-cell threshold prevents alignment padding from stealing useful subject/path space in the default 30-column split.

- [ ] **Step 3: Implement the minimum viewport helper**

Add near `picker_sel`:

```rust
fn viewport(selected: usize, len: usize, capacity: usize) -> std::ops::Range<usize> {
    if len == 0 || capacity == 0 {
        return 0..0;
    }
    let capacity = capacity.min(len);
    let start = (selected.min(len - 1) + 1)
        .saturating_sub(capacity)
        .min(len - capacity);
    start..start + capacity
}
```
